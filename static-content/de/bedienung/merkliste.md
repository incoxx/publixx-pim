# Merkliste

Die Merkliste ist eine persönliche Sammlung von Produkten, die Sie im Auge behalten möchten. Sie dient als Arbeitshilfe, um häufig benötigte Produkte schnell wiederzufinden, Produkte miteinander zu vergleichen und mit individuellen Notizen zu versehen. Jeder Benutzer verfügt über eine eigene, private Merkliste.

## Produkte zur Merkliste hinzufügen

Sie können Produkte an verschiedenen Stellen im anyPIM auf Ihre Merkliste setzen:

- **Produktliste** -- Klicken Sie auf das Lesezeichen-Symbol neben einem Produkt in der tabellarischen Übersicht.
- **Produktdetailansicht** -- Nutzen Sie die Schaltfläche **Zur Merkliste hinzufügen** im Kopfbereich der Detailansicht.
- **Suchergebnisse** -- Auch in der globalen Suche können Sie Produkte direkt über das Lesezeichen-Symbol merken.

Ein gefülltes Lesezeichen-Symbol zeigt an, dass sich das Produkt bereits auf Ihrer Merkliste befindet.

::: tip Hinweis
Die Merkliste ist benutzerspezifisch und für andere Anwender nicht sichtbar. Es gibt keine Begrenzung für die Anzahl der Produkte auf der Merkliste.
:::

## Merkliste anzeigen

Klicken Sie auf **Merkliste** in der Sidebar, um Ihre gespeicherten Produkte einzusehen. Die Merkliste zeigt eine tabellarische Übersicht mit folgenden Spalten:

| Spalte | Beschreibung |
|---|---|
| **SKU** | Eindeutige Artikelnummer des Produkts |
| **Name** | Produktbezeichnung in der aktuellen Sprache |
| **Status** | Aktueller Produktstatus |
| **Hinzugefügt am** | Zeitpunkt, zu dem das Produkt auf die Merkliste gesetzt wurde |
| **Notiz** | Optionale persönliche Notiz zum Produkt |

Ein Klick auf eine Zeile öffnet die Produktdetailansicht. Über das Kontextmenü (drei Punkte) können Sie einzelne Produkte von der Merkliste entfernen.

## Produkte von der Merkliste entfernen

Es gibt mehrere Wege, Produkte von der Merkliste zu entfernen:

- **Einzeln entfernen** -- Klicken Sie auf das gefüllte Lesezeichen-Symbol in der Merkliste, der Produktliste oder der Detailansicht.
- **Mehrfachauswahl** -- Aktivieren Sie die Checkboxen mehrerer Produkte in der Merkliste und klicken Sie auf **Ausgewählte entfernen**.
- **Merkliste leeren** -- Über die Schaltfläche **Alle entfernen** setzen Sie die gesamte Merkliste zurück.

::: warning Warnung
Das Leeren der Merkliste kann nicht rückgängig gemacht werden. Produktnotizen, die Sie auf der Merkliste hinterlegt haben, gehen dabei ebenfalls verloren.
:::

## Produktvergleich

Die Merkliste bietet eine Vergleichsfunktion, mit der Sie mehrere Produkte direkt nebeneinander betrachten können.

### Vergleich starten

1. Wählen Sie in der Merkliste mindestens zwei und maximal vier Produkte über die Checkboxen aus.
2. Klicken Sie auf die Schaltfläche **Vergleichen**.
3. Es öffnet sich die Vergleichsansicht.

### Vergleichsansicht

In der Vergleichsansicht werden die ausgewählten Produkte spaltenweise nebeneinander dargestellt. Jede Zeile entspricht einem Attribut:

| Element | Beschreibung |
|---|---|
| **Attributname** | Linke Spalte mit der Bezeichnung des Attributs |
| **Produktspalten** | Jeweils eine Spalte pro verglichenem Produkt mit dem entsprechenden Attributwert |
| **Unterschiede** | Abweichende Werte werden farblich hervorgehoben |

Sie können die Ansicht filtern, um nur abweichende Attribute anzuzeigen. Dadurch erkennen Sie auf einen Blick, worin sich die Produkte unterscheiden.

## Notizen

Zu jedem Produkt auf der Merkliste können Sie eine persönliche Notiz hinterlegen. Notizen eignen sich beispielsweise, um sich an offene Aufgaben zu erinnern oder den Grund für das Merken eines Produkts festzuhalten.

### Notiz hinzufügen oder bearbeiten

1. Klicken Sie in der Merkliste auf das Notiz-Symbol neben dem gewünschten Produkt.
2. Geben Sie Ihren Text in das Eingabefeld ein.
3. Bestätigen Sie mit **Speichern**.

Notizen werden nur Ihnen angezeigt und sind für andere Benutzer nicht einsehbar.

## Merkliste exportieren

Sie können den Inhalt Ihrer Merkliste als Datei exportieren, um die Daten ausserhalb des anyPIM weiterzuverwenden.

### Export durchführen

1. Klicken Sie in der Merkliste auf die Schaltfläche **Exportieren**.
2. Wählen Sie das gewünschte Format (CSV oder Excel).
3. Legen Sie fest, welche Attribute in den Export einfliessen sollen.
4. Starten Sie den Export mit **Herunterladen**.

Der Export enthält die Produktdaten aller Produkte auf Ihrer Merkliste, einschliesslich Ihrer persönlichen Notizen (optional).
