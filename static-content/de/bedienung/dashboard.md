# Dashboard

Das Dashboard ist die Startseite des anyPIM und bietet Ihnen einen kompakten Überblick über den aktuellen Stand Ihrer Produktdaten. Nach dem Login gelangen Sie direkt auf das Dashboard, das Ihnen die wichtigsten Kennzahlen, zuletzt bearbeitete Produkte und Schnellzugriffe auf häufig genutzte Funktionen anzeigt.

## KPI-Widgets

Im oberen Bereich des Dashboards werden zentrale Kennzahlen (Key Performance Indicators) als Kacheln dargestellt:

| Widget | Beschreibung |
|---|---|
| **Produktanzahl** | Gesamtzahl aller Produkte im System, aufgeschlüsselt nach Status (Entwurf, Aktiv, Inaktiv) |
| **Datenvollständigkeit** | Prozentualer Anteil der Produkte, bei denen alle Pflichtattribute ausgefüllt sind |
| **Letzte Änderungen** | Anzahl der Produkte, die in den letzten 24 Stunden bzw. 7 Tagen bearbeitet wurden |
| **Offene Aufgaben** | Anzahl der Ihnen zugewiesenen Workflow-Aufgaben mit Status „offen" |

Die Kennzahlen werden beim Laden des Dashboards in Echtzeit berechnet und spiegeln stets den aktuellen Datenbestand wider.

### Datenvollständigkeit im Detail

Das Widget zur Datenvollständigkeit zeigt einen Fortschrittsbalken, der den Befüllungsgrad über alle aktiven Produkte hinweg visualisiert. Ein Klick auf das Widget öffnet eine gefilterte Produktliste, die nur Produkte mit unvollständigen Pflichtattributen anzeigt. So können Sie gezielt an der Datenqualität arbeiten.

## Zuletzt bearbeitete Produkte

Unterhalb der KPI-Widgets finden Sie eine Liste der Produkte, die Sie zuletzt bearbeitet haben. Diese Liste zeigt die folgenden Informationen:

| Spalte | Beschreibung |
|---|---|
| **SKU** | Eindeutige Artikelnummer des Produkts |
| **Name** | Produktbezeichnung in der aktuellen Sprache |
| **Status** | Aktueller Produktstatus als farblich kodierter Badge |
| **Geändert** | Zeitpunkt der letzten Änderung (relativ, z.B. „vor 5 Minuten") |

Ein Klick auf eine Zeile navigiert Sie direkt zur Produktdetailansicht des jeweiligen Produkts. Die Liste umfasst standardmässig die letzten 10 bearbeiteten Produkte.

::: tip Hinweis
Die Liste der zuletzt bearbeiteten Produkte ist benutzerspezifisch. Jeder Anwender sieht ausschliesslich die Produkte, die er selbst zuletzt bearbeitet hat.
:::

## Schnellzugriffe (Quick Actions)

Am rechten Rand des Dashboards stehen Ihnen Schnellzugriffe zur Verfügung, mit denen Sie häufig genutzte Aktionen ohne Umwege starten können:

- **Neues Produkt anlegen** -- Öffnet direkt das Formular zur Produktanlage.
- **Produkte importieren** -- Startet den Import-Assistenten für CSV- oder Excel-Dateien.
- **Produktliste öffnen** -- Navigiert zur vollständigen Produktübersicht.
- **Offene Aufgaben anzeigen** -- Wechselt zur Workflow-Ansicht mit Ihren offenen Aufgaben.

Die verfügbaren Schnellzugriffe richten sich nach den Berechtigungen des angemeldeten Benutzers. Funktionen, für die keine Berechtigung vorliegt, werden nicht angezeigt.

## Widgets konfigurieren

Das Dashboard lässt sich individuell an Ihre Arbeitsweise anpassen. Jeder Benutzer kann die Zusammenstellung und Anordnung der Widgets nach seinen Bedürfnissen konfigurieren.

### Widgets ein- und ausblenden

1. Klicken Sie auf das Zahnradsymbol in der oberen rechten Ecke des Dashboards.
2. Es öffnet sich ein Konfigurationsdialog mit einer Liste aller verfügbaren Widgets.
3. Aktivieren oder deaktivieren Sie die gewünschten Widgets über die jeweiligen Schalter.
4. Bestätigen Sie Ihre Auswahl mit **Speichern**.

### Anordnung ändern

Die Reihenfolge der Widgets können Sie per Drag-and-Drop anpassen. Ziehen Sie ein Widget an die gewünschte Position, und das Dashboard speichert die neue Anordnung automatisch.

::: warning Warnung
Die Widget-Konfiguration wird pro Benutzer gespeichert. Administratoren können eine Standardkonfiguration festlegen, die für neue Benutzer als Vorlage dient.
:::

## Aktualisierung der Daten

Die Daten auf dem Dashboard werden beim Laden der Seite abgerufen. Wenn Sie aktuelle Werte sehen möchten, ohne die Seite neu zu laden, klicken Sie auf die Schaltfläche **Aktualisieren** im Kopfbereich des Dashboards. Einzelne Widgets lassen sich ebenfalls separat über das Aktualisierungssymbol in der jeweiligen Widget-Kopfzeile neu laden.
